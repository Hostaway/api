## Amenity object

```json
{
    "id": 1,
    "name": "Cable TV",
    "category": null
}
```

Property | Required | Type | Description
-------- | -------- | ---- | ----------- 
`id` | yes | int | 
`name` | yes | string | 
`category` | no | string | Category of the amenity, for example `Accessibility`. `null` when the amenity has no category.
